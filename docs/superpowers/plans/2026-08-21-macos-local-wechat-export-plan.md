# macOS 本地微信完整导出实施计划

> 依据：`docs/superpowers/specs/2026-08-21-macos-local-wechat-export-design.md`

## 可验证目标

用户从公共网站唤起 macOS 本地助手，在 localhost 页面选择微信 4.x 会话，由本机生成离线 HTML、分类媒体和完整性清单；网站无法读取联系人、正文、密钥或媒体。

## 阶段 1：隔离的本地助手骨架

- 新增 `local_helper/`，使用独立入口启动，强制绑定 `127.0.0.1`。
- 实现版本化的 `health`、`launch`、`task-status` 公共控制面。
- 实现 Host/Origin 白名单、一次性 challenge、短时令牌、重放保护和本地 UI 独立 Origin。
- 测试远程绑定、错误 Origin、DNS rebinding、过期/重放令牌。

## 阶段 2：macOS 微信数据发现与只读快照

- 发现微信 App 版本、`xwechat_files` 账号目录和 `db_storage` 数据库分片。
- 仅返回 localhost UI 所需的本地账号摘要。
- 实现同目录快照，包含 DB/WAL/SHM，并校验原文件未改变。
- 实现磁盘空间预检和安全临时目录。

## 阶段 3：密钥提取与 SQLCipher 解密

- 新增 SIP 状态检测与专家模式状态机；助手只提示 Recovery 手动步骤，绝不自动修改 SIP。
- 在 `local_helper/native/` 新增最小权限 C helper，仅接受 PID 和数据库 salt，通过 stdout 返回密钥候选。
- 实现 helper 源码哈希/路径校验，禁止执行任意外部程序。
- 使用 SQLCipher 在临时目录解密快照，密钥不写盘、不进日志。
- 通过 SQLite `integrity_check` 和 schema 指纹验证解密结果。
- 解密快照后写入无密钥恢复状态并立即停止；只有检测到 SIP 已重新启用才允许执行阶段 4–5。

## 阶段 4：联系人、会话和消息解析

- 实现微信 4.x 联系人和会话 schema 适配。
- 实现分片消息流式读取，避免百万级消息全量进内存。
- 实现统一消息模型、原始类型映射、XML/压缩载荷解析和未知类型兜底。
- 建立脱敏 schema 固件和各消息类型回归样本。

## 阶段 5：媒体解析与离线导出

- 按设计文档创建 12 个资源目录与 `export-manifest.json`。
- 实现安全媒体定位、内容哈希命名、流式复制、原件保留和派生格式转换。
- 实现单 HTML 模板、时间轴、搜索、类型筛选、引用跳转、媒体播放和分页/虚拟渲染。
- 实现输出临时目录、数量对账、媒体校验与原子更名。

## 阶段 6：网站接入

- 在现有“发现 → 微信聊天导出”中增加“本机微信 4.x”数据源。
- 未安装时显示阿里云下载地址、版本、CPU 架构、SHA-256 和权限教程。
- 已安装时仅展示连接/唤起/无隐私进度，不在公共网页展示联系人或正文。
- 保留 iOS/Finder 备份导出入口。

## 阶段 7：打包、文档和端到端验证

- 新增 arm64/x64 自包含 `.app` 打包配置、ad-hoc 签名、SHA-256 和 build manifest 脚本。
- 补充未签名 Beta、Gatekeeper、完全磁盘访问、辅助功能和卸载文档。
- 运行单元、契约、安全、集成、性能和实机端到端验证。

## 执行原则

- 先为每个核心边界编写失败测试，再实现最小代码使其通过。
- 每个阶段完成后运行定向 pytest 和 `ruff check`，阶段 7 运行全量测试。
- 不覆盖现有未提交修改，对脏文件采用小范围 patch。
- 任何真实聊天正文、解密数据库、密钥和媒体不进入仓库或测试输出。
