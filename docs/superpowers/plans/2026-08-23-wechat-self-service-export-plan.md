# 微信 4.1.12 网站自助导出实施计划

> 日期：2026-08-23
> 依据：`docs/superpowers/specs/2026-08-23-wechat-self-service-export-design.md`

## 阶段 1：公共网站与助手协议

1. 固化公共健康检查、版本兼容、一次性唤起票据和匿名任务状态协议。
2. 增加助手未安装、版本过旧、架构不匹配和下载失败状态。
3. 验证公共响应不包含账号、路径、数据库或聊天隐私。

## 阶段 2：本地用户状态机

1. 将当前账号确认、SIP、微信退出/启动、捕获、全库验证、解密和导出拆成明确阶段。
2. 为重启恢复、取消、超时、账号不匹配和删除任务数据增加状态转换与测试。
3. 保证所有密钥相关阶段只在同一工作进程内持有秘密。

## 阶段 3：本地页面产品化

1. 只显示脱敏账号序号、数据库数量和当前唯一动作。
2. 完善每个账号分别提取、重新提取时机、两次微信退出和 SIP 恢复说明。
3. 增加安装、授权、失败恢复、重试和数据删除界面。
4. 覆盖窄屏、键盘操作、加载、错误和长任务轮询。

## 阶段 4：发布与更新

1. 构建 Apple Silicon `.app`/`.dmg`，验证 LLDB、SQLCipher、zstandard 和静态资源完整。
2. 生成带版本、架构、Origin 和 SHA-256 的发布清单。
3. 验证网站下载安装、Gatekeeper 指引、唤起、升级和回退流程。

## 阶段 5：验证

1. 运行相关测试、完整 pytest 和本次范围 Ruff。
2. 使用测试账号按网站用户路径完成 4.1.12 真机验收。
3. 邀请未参与开发的 macOS 用户完成可用性验收。
4. 检查无密钥/隐私泄漏、无遗留进程、最终 SIP enabled。
5. 删除验收明文、任务数据和导出文件，更新用户文档与 Obsidian 笔记。

## 停止条件

- 任一数据库未覆盖或未通过 `sqlite_master` 时禁止导出。
- SIP disabled 时禁止读取任何聊天内容。
- 安装包来源、版本、架构或 SHA-256 不能验证时禁止发布。
- 用户流程需要隐藏命令或开发者旁路时，不得宣称可自助使用。
