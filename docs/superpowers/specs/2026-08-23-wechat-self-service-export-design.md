# 微信 4.1.12 网站自助导出设计

> 日期：2026-08-23
> 状态：待用户书面审核

## 目标

把已通过真机验证的微信 4.1.12 当前账号密钥提取、全库解密和聊天导出能力，产品化为普通用户可从网站发起的自助流程。发布前真机验收与普通用户使用完全走同一条路径，不允许依赖开发者旁路脚本。

“自助”不包括自动修改 SIP。用户必须亲自进入 macOS 恢复模式关闭和重新开启 SIP；网站和本地助手只提供步骤、状态检测和安全门禁。

## 隐私边界

- 公共网站只负责助手检测、下载安装、唤起和无隐私任务进度。
- 微信账号目录、密码、派生 key、salt、聊天正文、联系人、媒体、解密快照和导出文件只留在用户 Mac。
- LLDB、SQLCipher、数据库读取和 HTML 生成仅由 localhost 本地助手执行。
- 公共 API 不返回账号标识、文件路径、数据库名称或失败细节；本地私有页面可以显示脱敏账号序号和用户可操作的错误说明。
- 密钥不写日志、命令行、状态文件或磁盘；任务结束、失败、取消或助手重启后不得复用。

## 组件

### 公共网站

- 检测本地助手健康状态、版本和 API 兼容性。
- 未安装或版本过旧时展示 `.dmg` 下载、SHA-256 和 Gatekeeper 放行说明。
- 使用一次性票据唤起本地助手，不把网站登录凭证交给助手。
- 轮询匿名任务阶段和进度；隐私步骤切换到 localhost 页面完成。

### 本地助手

- 只监听 `127.0.0.1`，执行严格 Host、Origin、CSRF、一次性票据和本地会话校验。
- 发现本机账号目录，但 UI 只显示“账号 1/2”和数据库数量。
- 强制用户确认当前登录账号及“不同账号必须分别提取”的规则。
- 编排 SIP、LLDB 捕获、全库门禁、微信退出、快照、SQLCipher 解密、SIP 恢复和导出。
- 在用户完成或失败后提供删除解密快照与任务数据的操作。

### 发布与更新

- 为 Apple Silicon 构建独立 `.app` 和 `.dmg`，内含本地助手、LLDB 回调模块及 SQLCipher 运行依赖。
- 发布清单包含版本、架构、精确网站 Origin、下载地址、SHA-256 和最低兼容 API 版本。
- 网站拒绝未知来源、校验值非法、架构不匹配或过旧的助手。

## 用户流程

1. 用户在网站点击“导出微信聊天”。
2. 网站检测助手；未安装时引导下载、安装并通过 Finder 手动打开。
3. 网站用一次性票据唤起助手，本地私有页面打开。
4. 助手显示微信版本、SIP 状态和脱敏账号目录列表。
5. 用户选择当前登录账号，并确认不同账号需要分别提取。
6. 页面按 Apple Silicon/Intel 分别展示关闭 SIP 的恢复模式步骤。
7. 用户关闭 SIP 并重启后恢复任务，完全退出微信，点击开始提取。
8. 助手请求一次管理员授权并等待微信启动；用户启动微信并登录已确认账号。
9. LLDB 捕获一次账号密码，分离并恢复微信；助手派生并验证当前账号全部数据库 key。
10. 用户再次完全退出微信；助手创建一致快照，逐库解密和查询 `sqlite_master`。
11. 页面强制提示重新开启 SIP，SIP disabled 时禁止读取联系人和聊天。
12. 用户开启 SIP 并重启后恢复任务，加载会话目录。
13. 用户选择会话，生成离线 HTML、分类媒体和完整性清单。
14. 页面说明本次只完成当前账号；其他账号必须分别登录并重新运行。
15. 用户下载/打开导出结果后，可删除解密快照和任务状态。

## 状态与提示

本地页面至少展示以下阶段：

- 检查环境
- 等待账号确认
- 等待关闭 SIP
- 等待退出微信
- 等待启动并登录微信
- 捕获与全库验证
- 等待再次退出微信
- 创建快照与逐库解密
- 等待重新开启 SIP
- 加载会话
- 导出中
- 完成、部分完成或失败

每个阶段必须说明当前需要用户执行的唯一动作、是否会重启、数据是否保留，以及失败后的恢复方式。UI 不显示 key、salt、完整账号 ID、内部路径或 LLDB 输出。

## 错误与恢复

- **助手不可达**：网站展示安装、启动和防火墙检查，不伪装为成功。
- **助手版本不兼容**：要求下载安装匹配版本，不调用旧 API。
- **微信版本不支持**：当前只接受已真机验证的 4.1.12。
- **账号不匹配**：全库首页验证失败后拒绝继续，提示登录所选账号并重新提取。
- **授权取消或捕获超时**：终止 LLDB、恢复微信、清零密码并提供重试。
- **PID 变化或微信退出**：按当前阶段安全重试或失败；不复用旧地址。
- **部分数据库未覆盖**：禁止进入快照和解密。
- **快照变化或磁盘空间不足**：保留源数据库不变，清理不完整输出并提示处理方法。
- **FTS 扩展库**：所有库强制读取 `sqlite_master`；普通库继续完整性检查，含虚拟表的库允许系统 SQLite 缺少微信扩展导致的完整性检查异常。
- **SIP 未恢复**：禁止读取联系人、会话、消息或媒体。
- **导出失败**：在 SIP 已开启的前提下保留已验证快照供重试，并提供立即删除入口。

## 测试策略

### 自动化测试

- 公共网站助手检测、下载清单、版本和架构门禁。
- localhost Host、Origin、CSRF、票据和会话安全。
- 账号规则确认、脱敏显示和账号不匹配。
- 模拟 LLDB 成功、超时、取消、进程退出、参数异常和可靠分离。
- 全库覆盖门禁、SQLCipher、FTS、`sqlite_master`、快照一致性和磁盘不足。
- SIP 各阶段门禁、重启恢复和密钥不持久化。
- 4.1.12 会话目录、无消息计数 schema、压缩消息、媒体、HTML 与清单。
- 删除任务数据与失败输出清理。

### 发布前真机验收

验收人员使用测试微信账号，严格按网站页面完成下载安装、Gatekeeper 放行、账号确认、两次 SIP 操作、微信启动/退出、管理员授权、全库解密、会话选择和 HTML 导出。额外检查：

- 当前账号全部数据库均覆盖并实际解密。
- 真实会话和至少一条压缩消息可解析。
- HTML 离线打开，清单计数与数据库实际行数一致。
- 密钥不出现在日志、状态文件、进程参数和任务目录。
- 完成、取消和超时后无遗留 LLDB/helper 子进程。
- 最终 SIP 为 enabled，验收明文和任务数据按计划删除。

### 用户可用性验收

由未参与开发的全新 macOS 用户，仅按照网站页面说明完成一次测试账号导出。若需要开发者口头补充隐藏步骤，则验收失败。

## 发布门禁

以下条件全部满足才可标记可用：

1. 自动化测试和本次改动范围 Ruff 通过。
2. Apple Silicon 微信 4.1.12 真机用户路径通过。
3. 全新 macOS 用户可用性验收通过。
4. 安装包、SHA-256、版本更新和下载回退路径验证通过。
5. 无隐私上传、无密钥落盘、无遗留调试器。
6. 最终 SIP 为 enabled。

## 非目标

- 自动修改 SIP、NVRAM、Gatekeeper 或完全磁盘访问权限。
- 支持未经真机验证的微信版本、Intel 微信二进制或 Windows。
- 在服务器保存、分析或转换用户聊天数据。
- 一次提取覆盖多个微信账号。
