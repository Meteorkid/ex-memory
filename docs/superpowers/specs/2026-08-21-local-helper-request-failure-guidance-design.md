# 本地助手请求失败引导设计

## 目标

本地微信导出页面发生任何 API 请求失败时，不再只显示“请求失败”。页面必须保留可用的原始错误信息，并固定展示 macOS“完全磁盘访问”授权步骤，让普通用户能够继续排查。

## 交互规则

错误区域按以下顺序展示：

1. 原始错误信息；没有具体信息时显示“请求失败”。
2. 提示用户打开“系统设置 → 隐私与安全性 → 完全磁盘访问”。
3. 展示固定操作步骤：
   1. 点击 `+`。
   2. 选择 `/Applications/ex-memory 微信导出助手.app`。
   3. 打开应用右侧的权限开关。
   4. 如果系统要求，输入 Mac 密码。
4. 提示授权后重新启动助手并刷新当前页面。

发生错误后禁用当前阶段的操作按钮，避免用户在依赖状态未知时重复提交。页面刷新并成功取得环境状态后，恢复正常交互。

## 实现范围

- 修改 localhost 私有导出页面的通用 API 错误渲染逻辑。
- 环境检测明确返回 `full_disk_access_required` 时使用同一份引导。
- 不修改公共网站认证、助手安全边界、SIP 流程或导出逻辑。
- 不自动修改“完全磁盘访问”权限，也不代替用户输入系统密码。

## 错误处理

- HTTP 错误优先展示服务端 `detail`。
- 无法解析响应、连接中断或其他未知错误使用“请求失败”。
- 所有上述错误均附带相同的完全磁盘访问步骤。

## 验证

- 测试生成的本地页面包含完整的 4 步说明和应用绝对路径。
- 测试通用请求失败分支调用统一错误渲染逻辑。
- 运行本地助手安全相关测试及 Ruff 检查。
