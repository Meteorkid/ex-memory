# 本地微信导出页暗色主题设计

## 目标

将 localhost 私有微信导出页面调整为与 ex-memory 主站一致的暗色主题，同时保持现有页面结构、导出流程、安全边界和错误引导不变。

## 视觉规则

- 页面背景使用项目主背景 `#0a0a12`，卡片使用 `#12121e` 与 `#1a1a28` 层级。
- 主操作、焦点和选中状态使用项目紫色 `#7c6cff`；悬停使用 `#9b8aff`。
- “导出全部聊天”和成功状态使用微信绿色 `#07c160`，表达最终导出动作与完成状态。
- 主文本、次要文本和弱化文本沿用项目暗色主题的白色透明度层级。
- 输入框、选择框、状态栏、会话按钮和代码块使用暗色表面与紫色半透明边框。
- 权限错误使用暗红半透明卡片，专家模式警告使用暗橙半透明卡片，保证警示明确且不出现浅色突兀区域。
- 卡片保留圆角，但增加细边框和轻微紫色阴影，使其与主站的悬浮层次一致。

## 交互规则

- 主流程按钮默认为紫色渐变；“导出全部聊天”单独使用绿色渐变。
- 按钮悬停时提高亮度并轻微上移，禁用时降低透明度且不发生位移。
- 输入框获得焦点时显示紫色边框与柔和光晕。
- 会话选中状态使用紫色描边；成功或完成信息使用绿色，不用颜色替代文字说明。
- 支持 `prefers-reduced-motion`，用户关闭动画时取消位移和过渡。

## 响应式与可访问性

- 保持单列布局，桌面最大宽度不变；窄屏降低页面边距和卡片内边距。
- 文本与背景保持清晰对比，交互元素保留可见的键盘焦点状态。
- 保留语义标题、按钮、输入框和选择框，不改变现有 DOM 功能标识。

## 实现范围

- 只修改 `local_helper/api.py` 内本地导出页的内联样式，并按需增加不影响逻辑的语义 class。
- 不抽离新 CSS 资源，不修改 PyInstaller 打包规则。
- 不修改公共网站、API、SIP 状态机、微信数据库读取或 HTML 导出功能。

## 验证

- 页面响应中包含项目暗色背景、紫色强调色和绿色导出按钮样式。
- 原有完全磁盘访问四步说明和行为测试继续通过。
- 运行本地助手安全测试、Ruff 和差异检查。
- 重新构建本机测试版 `.app`，校验签名并确认健康检查通过。
